## 摘要
Renault、Bergeaud 和 Bosquet（以下简称 RBB）认为，将作者摘要首次被标记的月份作为大语言模型（LLM）采用的时间点，会引发一种停止时间选择，即使在没有因果效应的情况下，也可能产生正向的事件研究路径。尽管这种机制在数学上是可能的，但它并不构成零效应的证明。通过将 RBB 自己的随机安慰剂重新校准为检测器的实际标记率，我们表明测得的关联远高于这一基准，因此该人为偏差太小，不足以解释生产力的变化。我们进一步通过一系列互补设计重新估计了 LLM 采用与生产力之间的关联，在这些设计中，时间偏差不会对估计产生偏误：包括在一年确定采用时间并在另一年测量产出的前后对比、双重差分法的保守对照组、从未定义采用日期的基于强度的设定，以及保持标记率固定的基于排名的测量。在所有这些估计中，正向的生产力关联依然存在，而在 ChatGPT 出现前的安慰剂数据上进行的相同测试则显示为零效应。RBB 识别出的人为偏差是真实存在的，但是有限的，它无法解释我们报告的模式。

## Abstract
Renault, Bergeaud, and Bosquet (hereafter RBB) argue that dating LLM adoption as the first month in which an author's abstract is flagged induces a stopping-time selection that can produce a positive event-study path even when there is no causal effect. Although this mechanism is mathematically possible, it does not constitute proof of a null effect. Recalibrating RBB's own random placebo to the detector's realized flag rate, we show that the measured association stays well above this benchmark, so the artifact is too small to explain the productivity changes. We further re-estimate the association between LLM adoption and productivity with a series of complementary designs in which the timing artifact cannot bias the estimate: a before-and-after comparison that dates adoption in one year and measures output in another, a conservative control group for difference-in-differences, an intensity-based specification that never defines an adoption date, and a rank-based measurement holding the flag rate fixed. A positive productivity association persists across all of these estimates, while the same tests run on pre-ChatGPT placebo data return null effects. The artifact RBB identify is real but bounded, and it does not account for the pattern we report.
